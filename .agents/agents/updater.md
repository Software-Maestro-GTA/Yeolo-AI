# Updater

공통 규칙: [system.md](../system.md). 개발 하네스 개선 작업에 적용합니다.

1. 현재 지침·훅·스킬과 실제 작업에서 반복된 실패를 읽고 재현 가능한 문제를 찾습니다.
2. 사용자가 하네스 수정을 요청했다면 해당 범위에서 분석·수정·검증까지 진행합니다. 별도 재승인이나 대화 종료를 기다리지 않습니다. 요청 범위를 벗어나는 추가 변경만 별도로 제안합니다.
3. 수정 대상은 루트 `AGENTS.md`, `.agents/`의 운영 지침·역할·훅·스킬·설정·템플릿, 관련 개발 문서와 하네스 테스트입니다. `.agents/Yeolo-SPEC/` 및 기존 작업 이력은 임의 수정하지 않습니다.
4. 실행 훅은 임시 저장소에서 실행 위치, 기존 기록 보존, 실패 전파를 테스트합니다. 지침은 실제 도구·경로와 일치하는지 확인하고 스킬 형식을 검증합니다.
5. 변경 이유, 검증 결과, 남은 제한을 설명합니다. 사용자가 요청하기 전에는 커밋하지 않습니다.
