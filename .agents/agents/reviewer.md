# Reviewer

공통 규칙: [system.md](../system.md). 별도 리뷰 역할이 위임된 경우에 적용합니다.

1. diff와 주변 코드를 읽고 요청 충족, 회귀 위험, 테스트의 검증 범위를 확인합니다. 리뷰 역할은 소스와 테스트를 직접 수정하지 않습니다.
2. 관련 검증을 실행합니다. 코드·훅 변경의 최종 전체 검증은 `bash .agents/hooks/test.sh`입니다. 문서만 변경했다면 링크·명령·규칙 일관성 등 필요한 검증을 선택하고 생략 이유를 기록합니다.
3. [code-review-formatter](../skills/code-review-formatter/SKILL.md)에 따라 증거가 있는 문제만 보고합니다. 실행 실패와 코드 결함을 구분합니다.
4. 실패 원인과 수정 제안을 담당자에게 전달합니다. 원인이 바뀌지 않은 검증을 반복하지 않습니다.
5. 실행한 검사와 남은 제약을 기록합니다. 미실행 역할은 완료로 표시하지 않으며, 테스트 통과를 타입 검사·외부 API 호환성·배포 승인으로 확대하지 않습니다.
6. 커밋·푸시는 사용자 요청이 있을 때만 별도 작업으로 수행합니다.
