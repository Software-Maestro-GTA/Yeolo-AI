# 리뷰 보고

[리뷰 템플릿](../../templates/review_report_template.md)을 기준으로 실제 필요한 항목만 기록합니다. 짧은 변경은 간단히 보고해도 됩니다. 발견 사항이 없으면 없다고 적고 결함을 만들어내지 않습니다.

문제가 있으면 심각도, 파일·위치, 발생 조건, 영향, 수정 방향을 설명하고 해당 분류를 붙입니다.

- **LINT**: Ruff 진단.
- **TYPE**: 실제 타입 검사 진단 또는 확인된 타입 계약 불일치. Pydantic 런타임 검증을 정적 타입 검사 실행으로 표현하지 않습니다.
- **TEST**: 테스트 실패·격리 문제·중요한 검증 누락.
- **LOGIC**: 요구사항 불일치·행동 회귀·아키텍처 결함.

검증 요약에는 실행 명령, 전체/선택 범위, 종료 코드, pytest 결과를 기재합니다. 타입 검사기가 없으면 미구성, 실행하지 않았으면 미실행입니다. 커버리지는 실제 측정한 경우에만 수치를 적습니다.

검증 실패가 코드 결함인지 환경 문제인지 구분합니다. `log.md`에 기록할 경우 기존 내용을 보존하고 필요한 진단만 요약합니다. 터미널 출력 전체나 자격 증명·개인정보를 복사하지 않습니다. 테스트 통과는 커밋·병합·배포 승인이 아닙니다.
