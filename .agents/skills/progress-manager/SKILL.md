# 작업 진척 기록

단순 수정에 별도 보드를 강제하지 않습니다. 보드가 필요하면 루트에서 `bash .agents/hooks/init.sh`를 실행합니다. [템플릿](../../templates/progress_template.md)은 새 보드에만 사용하며 기존 보드를 덮어쓰지 않습니다.

- 현재 작업의 목표, 범위, 인수 조건, 필요한 구현·검증 항목을 작성합니다. 이슈 번호와 명세 링크는 실제 존재할 때만 적습니다.
- 보드가 다른 작업의 기록이면 기존 내용을 보존하고 새 작업 구역을 추가합니다. 같은 작업이면 해당 구역만 갱신합니다.
- 실제 담당자와 상태(대기/진행중/완료/미실행/차단)를 기록합니다. 단일 에이전트가 수행했다면 그 사실을 적고, 가상의 네 역할을 완료로 채우지 않습니다.
- 검증 기록에는 명령, 전체/선택 범위, 종료 코드, 테스트 결과와 남은 제약을 적습니다. Ruff를 타입 검사로, 테스트 개수를 커버리지로 기록하지 않습니다.
- 인수 조건과 필요한 검증을 충족한 경우에만 완료로 표시합니다. 테스트가 불필요한 변경은 근거를 적고 해당 없음으로 표시할 수 있습니다.
